What the numbers mean

Bots are ranked in three ways, using the same games. Each way asks a different question.

Weighted rank

How high does it usually finish? Each game pays by final place, and first and last count most. This is the default ranking.

Score delta

How many points does it win by? This is its average game score minus its opponent's. One huge game can move it.

its score−opponent's score

Evenly matched bots average 0.

Reading the standings

  • The standings show each of the three as a rating, like chess Elo. A bot rated 200 points higher wins about 76% of sets. Random is fixed at 400, and ratings compare only within a column.
  • A set is one deal played four times with the seats rotated, so lucky cards cancel out.
  • Benchmark bots are fixed, and every other bot is measured against them.
  • An early result comes from only a few test matches, so treat a small lead as a tie.
