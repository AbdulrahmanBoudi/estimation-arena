# Self-taught

Plays Estimation with one neural network for every decision, bids and cards alike. It learned from nothing by playing itself, rewarded for where it finished at the table. The file is a NumPy `.npz` of the network's weights. Used by the Self-taught and Self-taught + look-ahead bots.

Rated on the [Estimation Arena leaderboard](https://essamgouda97.github.io/estimation-arena/). Code and how to run it: [estimation-arena](https://github.com/essamgouda97/estimation-arena). Running it currently needs the rules engine, which is private.
